# 有限机会下的任务承诺核对

本工具枚举两次被动搭载机会，比较逐轨迹离线接纳与面对允许未来的共同任务承诺。另核对单任务需求变化中，首次新报告之前的年龄违约。执行使用理想整数微秒，不调用 P4、BMv2 或 Mininet。

## 两步模型

对象为 X、Y，两者在窗口开始时各有一个生成于 -100 ms 的已收样本。窗口为 [0,200] ms。第一次机会在 0 ms，可以搭载 X 或 Y。第二次机会在 100 ms，只能搭载 X 或只能搭载 Y，两个未来有相同的第一步历史。资格对应固定路径上的对象，每包至多 K 条记录。它是独立的小拓扑抽象，不是现有三节点分支拓扑的网络执行。

第一次动作在两个未来间相同。第二次观察当前包资格后可以自由选记录，包含对部署能力的有利放宽。报告使用固定、已知的延迟，没有丢失和时钟不确定性。总记录数量计预算。非空搭载另统计一次报告尝试，不包含固定头、字节传播、API 或提示传输费用。

接纳集合在所有未来间相同，表示事先作出的任务承诺。逐轨迹离线参照允许为各轨迹选择不同的接纳集合，不能把最小接纳数量当成某个共同可承诺集合。允许提示的变体在共同承诺后、第一次搭载前获知第二步分支。它可以改变动作，不能事后替换已承诺任务。提示的获取过程和物理费用没有实现。

期限为 150/200/250/300 ms，延迟为 0/20/60 ms，K 为 1/2，总记录预算为 1/2/3，提示开关为两种，共 144 个配置。另有两种异质期限的四个配置。所有组合均保留，不将配置数视为随机重复。

代表性输入为期限 200 ms、延迟 0、K=1、记录预算 2。每个未来各能离线接纳两个任务，共同因果承诺只能接纳一个。提前获知分支或放宽为 K=2，可在该记录预算下接纳两个。这个结果说明信息前提与容量的作用，没有实现新编排算法或证明它优于其他方法。

期限放宽为 300 ms 时，初始样本本身足够覆盖整个有限窗口，可以不生成新记录。期限收紧为 150 ms 的部分输入中，两条轨迹可离线接纳的对象分别为 X 和 Y，没有共同可承诺对象。获知未来搭载分支也不能改变事先作出的承诺。

## 通知提前量模型

需求于 100 ms 变更，初始样本生成于 0 ms，新的期限为 150 ms，窗口为 [100,300] ms。机会从 100 ms 开始，每 20 ms 一次。授权在通知时间加安装延迟后生效，之后每包采样。此前旧配置没有新的合格报告。给定的初始缓存、机会及旧配置状态是这个模型的前提。

枚举提前量 0/20/40/60/100 ms、安装延迟 0/20/60/100 ms、报告延迟 0/20/60 ms，共 60 个配置。函数返回最早新报告可用时间、新报告前不可避免的违约时长，以及完整窗口的连续年龄。生效时刻相等的包可以使用新配置，不模拟 RPC、在途包切换或跨节点原子性。

安装 60 ms、报告 20 ms 时，提前量 0、20、40 ms 的首报分别于 180、160、140 ms 可用，违约时长分别为 30、10、0 ms。更早授权也增加记录尝试数量，输出保留这项变化。不能由此声称相同字节预算下有性能提升。

## 复现

在项目根目录运行，无须 root 和额外依赖：

```bash
python3 -m unittest discover -s tests -v
python3 experiments/run_causal_contract.py \
  --output data/causal-contract/new-run
python3 experiments/check_causal_contract.py \
  --run data/causal-contract/new-run \
  --output data/causal-contract/new-audit/checks.json
```

输出目录必须不存在。`specification.json` 保存全部输入规则，`frontiers.json` 保存逐配置承诺集合与动作证据，`deployment.json` 保存控制网格，`manifest.json` 保存状态、软件版本、主机负载、源码和产物摘要。`executed-source/` 保留实际执行源码。源码版本变化时创建新运行，历史数据不覆盖。

独立检查器不调用被测模型，另枚举全部两步动作，以窗口开始、报告可用前的左极限和窗口结束检查连续期限覆盖。它还检查非预知约束、预算、配置完整性和动作证据。

当前记录为 [model-02](../data/causal-contract/model-02/summary.json)，独立检查为 [audit-02](../data/causal-contract/audit-02/checks.json)。本轮新增 11 项单元检查，全部 119 项通过。`model-01` 与 `audit-01` 保留为首次完成记录。02 明确了提示在共同承诺之后到达，增加共同承诺身份检查并加强独立核对，模型结果不变。

本模型未给出无限期保证、随机尾界、一般竞争比或实际协议成本，也不支持依据这组确定性配置给出方法排名。
